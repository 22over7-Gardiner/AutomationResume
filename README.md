# AutomationResume

David Gardiner's automation and Industry 4.0 technical portfolio. The site demonstrates a connected-manufacturing concept using synthetic data only.

## Local development

```bash
npm install
npm run dev
```

## Production build

```bash
npm run build
npm run preview
```

## GitHub Pages

The Vite base path is configured for the `AutomationResume` repository. The included GitHub Actions workflow builds and deploys the `dist` directory.

After uploading these files, open the repository's **Settings > Pages** and select **GitHub Actions** as the source.

Expected project URL:
`https://22over7-gardiner.github.io/AutomationResume/`

## Safety

Do not commit credentials, company-confidential files, proprietary equipment details, internal screenshots, or real manufacturing data.
